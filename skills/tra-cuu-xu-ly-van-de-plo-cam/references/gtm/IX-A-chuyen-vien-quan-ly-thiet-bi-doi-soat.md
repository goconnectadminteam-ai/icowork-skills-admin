5. Chuyên viên Quản lý Thiết bị & Đối soát
| Cột | Nội dung cần điền |
| Cấp/Chức danh | Chuyên viên Quản lý Thiết bị & Đối soát |
| Mục tiêu | Đảm bảo vòng đời thiết bị Camera (nhập kho – định danh – phân bổ – thu hồi – RMA – |
| đối soát) được vận hành thông suốt, chính xác trên toàn quốc; là đầu mối đối soát số liệu |
| thiết bị với VNPT Tech và xử lý các trường hợp thiếu dữ liệu/sai lệch. |
| KPI (tách Giữ/Mới) | ● Tỷ lệ thiết bị được gắn định danh, phân bổ đúng cấp trên tổng số thiết bị nhập kho. ● Tỷ lệ hồ sơ RMA hoàn tất đúng SLA (1 đổi 1). ● Tỷ lệ sai lệch dữ liệu serial/số lượng thiết bị giữa OneBSS/PSIS và thực tế kho. ● Tỷ lệ hoàn tất đối chiếu kỳ với VNPT Tech đúng hạn |
| Hành động | - Theo dõi, giám sát chỉ số quản lý thiết bị toàn quốc (nhập kho, định danh, phân bổ, thu |
| hồi, RMA) do Bộ phận kỹ thuật VNPT T/TP thực hiện. |
| - Truy nguyên, xử lý các trường hợp thiếu dữ liệu serial hoặc sai lệch phát sinh trong |
| quá trình nhập kho/thu hồi. |
| - Lập hồ sơ RMA, gửi VNPT Tech đối với thiết bị lỗi/hỏng cần đổi trả. |
| - Đến kỳ đối soát tháng: trích xuất dữ liệu từ PSIS (số thiết bị nhận, số RMA gửi trả, số |
| thiết bị tồn), đối chiếu với Phòng Điều hành kinh doanh VNPT T/TP và VNPT Tech, |
| chốt bảng đối chiếu kỳ trước ngày 10 tháng kế tiếp. |
| - Quản trị danh mục SKU thiết bị Camera phối hợp Ban Sản phẩm. |
| Quy trình phải | Luồng 3.1–3.9 (Inventory thiết bị Camera). Luồng 7.4 (Đối soát NCC – VNPT Tech). |
| biết (tham chiếu) |
| Điều hành (quyết định gì) | - Quyết định phương án xử lý ngoại lệ khi phát hiện sai lệch dữ liệu thiết bị (thiếu serial, lệch tồn kho) trong phạm vi quy trình đã ban hành (VB577/QĐ-VNPT-CLG). |
| Dashboard | - Theo dõi toàn quốc: số lượng thiết bị nhập kho/tồn/phân bổ theo tỉnh, tỷ lệ định danh |
| đúng hạn, tỷ lệ hồ sơ RMA đúng SLA. |
| - Quyết định thời điểm chốt số liệu đối soát kỳ với VNPT Tech. |
| - Escalate lên Trưởng PLO Camera/Ban Sản phẩm đối với sai lệch lớn hoặc tranh chấp |
| số liệu không tự xử lý được với VNPT Tech. |
