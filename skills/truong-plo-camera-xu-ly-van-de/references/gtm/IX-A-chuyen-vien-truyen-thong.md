4. Chuyên viên truyền thông
| Cột | Nội dung cần điền |
| Cấp/Chức danh | Chuyên viên truyền thông |
| Mục tiêu | Đảm bảo mọi thông báo, chính sách, chương trình liên quan PLO Camera (khuyến mại, |
| thay đổi giá/gói cước, thông báo sự cố, chương trình thi đua...) được truyền thông đầy |
| đủ, đúng thời điểm, đúng đối tượng tới khách hàng và toàn bộ chuỗi thực thi tại |
| Tỉnh/Thành phố. |
| KPI (tách Giữ/Mới) | - Tỷ lệ truyền thông kịp thời (đúng SLA thời gian quy định) trên tổng số chiến dịch/thông báo cần gửi. |
| Hành động | - Soạn, biên tập nội dung truyền thông cho gói cước, chương trình hành động |
| - Tỷ lệ tiếp cận trên tổng số thuê bao mục tiêu |
| - Tỷ lệ khiếu nại phát sinh sau thông báo chính sách/giá |
| Quy trình phải | Luồng 2.10 (Truyền thông giới thiệu sản phẩm). Luồng 5.10 (Truyền thông chính sách/kết quả tới thuê bao). Luồng 8.7–8.10 (Truyền thông khủng hoảng & nội bộ). |
| biết (tham chiếu) |
| Điều hành (quyết định gì) | - Quyết định kênh, thời điểm, tần suất gửi truyền thông trong phạm vi kế hoạch/ngân sách chiến dịch đã được Trưởng PLO Camera/Ban Sản phẩm phê duyệt. - Gửi thông báo/chiến dịch qua các kênh tới đúng đối tượng, đúng thời điểm. - Phối hợp TT DVKH khi cần gửi thông báo liên quan sự cố kỹ thuật hoặc thay đổi chính sách/giá. - Tổng hợp số liệu tiếp cận, đối chiếu với sản lượng PTM thực tế; |
| Dashboard | - Theo dõi tỷ lệ gửi thành công/tiếp cận theo từng chiến dịch, tỷ lệ khiếu nại phát sinh |
| sau thông báo, so sánh nhóm Giữ/Mới. |
| - Quyết định điều chỉnh nội dung/hình thức truyền thông khi tỷ lệ tiếp cận hoặc tỷ lệ |
| khiếu nại vượt ngưỡng cảnh báo. |
| Luồng 2.10 (Truyền thông giới thiệu sản phẩm). Luồng 5.10 (Truyền thông chính |
| sách/kết quả tới thuê bao). Luồng 8.7–8.10 (Truyền thông khủng hoảng & nội bộ). |
